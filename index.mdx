clap makes it easy to build professional command-line interfaces in Rust. Whether you prefer declaring your CLI with derive macros on a struct or constructing it programmatically with the builder pattern, clap gives you auto-generated help text, shell completions, type-safe argument parsing, subcommand support, and much more—out of the box.

## Get Started in 3 Steps

<Steps>
  <Step title="Add clap to your project">
    Add clap as a dependency with your preferred features.

    ```toml Cargo.toml
    [dependencies]
    clap = { version = "4", features = ["derive"] }
    ```
  </Step>
  <Step title="Define your CLI">
    Declare arguments using the derive macro on a struct.

    ```rust main.rs
    use clap::Parser;

    /// A simple greeting tool
    #[derive(Parser, Debug)]
    #[command(version, about)]
    struct Args {
        /// Name of the person to greet
        #[arg(short, long)]
        name: String,

        /// Number of times to greet
        #[arg(short, long, default_value_t = 1)]
        count: u8,
    }

    fn main() {
        let args = Args::parse();
        for _ in 0..args.count {
            println!("Hello {}!", args.name);
        }
    }
    ```
  </Step>
  <Step title="Run your program">
    clap automatically generates help text, handles errors, and parses arguments.

    ```console
    $ cargo run -- --name Alice --count 3
    Hello Alice!
    Hello Alice!
    Hello Alice!

    $ cargo run -- --help
    A simple greeting tool

    Usage: greet [OPTIONS] --name <NAME>

    Options:
      -n, --name <NAME>    Name of the person to greet
      -c, --count <COUNT>  Number of times to greet [default: 1]
      -h, --help           Print help
      -V, --version        Print version
    ```
  </Step>
</Steps>

## Choose Your API

<Tabs>
  <Tab title="Derive API (recommended)">
    The derive API uses Rust macros to generate argument parsing from your struct definitions. It's concise, readable, and keeps argument declarations co-located with the variables that hold them.

    ```rust
    use clap::{Parser, Subcommand, ValueEnum};

    #[derive(Parser)]
    #[command(version, about)]
    struct Cli {
        #[command(subcommand)]
        command: Commands,

        #[arg(long, global = true)]
        verbose: bool,
    }

    #[derive(Subcommand)]
    enum Commands {
        /// Build the project
        Build {
            #[arg(long)]
            release: bool,
        },
        /// Run tests
        Test {
            /// Filter tests by name
            filter: Option<String>,
        },
    }
    ```
  </Tab>
  <Tab title="Builder API">
    The builder API gives you full programmatic control over your parser. It's ideal when argument definitions need to be constructed dynamically at runtime.

    ```rust
    use clap::{Command, Arg, ArgAction, arg};

    let matches = Command::new("myapp")
        .version("1.0")
        .about("A sample application")
        .arg(
            Arg::new("verbose")
                .short('v')
                .long("verbose")
                .action(ArgAction::SetTrue)
                .help("Enable verbose output"),
        )
        .arg(arg!(<INPUT> "Input file to process"))
        .get_matches();

    let verbose = matches.get_flag("verbose");
    let input = matches.get_one::<String>("INPUT").unwrap();
    ```
  </Tab>
</Tabs>
